# bonezmod

Read-only MMR reveal overlay for Rocket League. Transparent card
listing every player in the current lobby with their tier, badge,
current MMR, peak, and W/G.

Fully external — no injection, no memory access, no input emission,
no contact with `RocketLeague.exe`. Same risk class as having
tracker.gg open on a second monitor.

See [`LAUNCH.md`](LAUNCH.md) for features, build, run, and safety.
